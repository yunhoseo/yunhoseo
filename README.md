### Research Interests

- **Multi-Camera Multi-Object Tracking (MC-MOT)** — appearance-free, position/time-based cross-camera association
- Occlusion-robust tracking in manufacturing and logistics scenes
- Anomaly detection on manufacturing process data (vision inspection variables, equipment logs)
- LLM agents for research workflows (multi-agent orchestration, citation-grounded writing)

### Selected Projects
